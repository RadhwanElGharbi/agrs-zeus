## WRI Aqueduct Floods (Best Option for Direct Download)

The **WRI Aqueduct Floods dataset** provides the most accessible direct download option for 100-year riverine flood hazard data.[1][2]

**Direct Download Access:**
- **S3 Bucket Base URL**: `https://wri-projects.s3.amazonaws.com/AqueductFloodTool/download/v2/`
- **File Structure**: `inunriver_[climatescenario]_[model]_[year]_rp[returnperiod].tif`
- **Example for 100-year baseline**: `inunriver_historical_000000000WATCH_1980_rp00100.tif`
- **Format**: GeoTIFF showing inundation depth in meters
- **Resolution**: 1000 meters (~30 arc-seconds)
- **Coverage**: Global
- **Return Periods Available**: 2, 5, 10, 25, 50, 100, 250, 500, 1000 years[2]

**Download Command:**
```bash
wget https://wri-projects.s3.amazonaws.com/AqueductFloodTool/download/v2/inunriver_historical_000000000WATCH_1980_rp00100.tif
```

**License**: Free to use with attribution to World Resources Institute; no restrictions on use or distribution.[2]

## Google Earth Engine Access

**Dataset ID**: `WRI/Aqueduct_Flood_Hazard_Maps/V2`[2]

**JavaScript Code Example:**
```javascript
var dataset = ee.ImageCollection('WRI/Aqueduct_Flood_Hazard_Maps/V2')
  .filter(ee.Filter.eq('floodtype', 'inunriver'))
  .filter(ee.Filter.eq('returnperiod', 100));
```

This provides programmatic access without manual downloads.[2]

## Global Flood Database

**Direct Download via Google Cloud Storage:**
- **GCS Bucket**: `gs://gfd_v1_4`
- **Format**: GeoTIFF
- **Coverage**: 913 individual flood events (2000-2018), not continuous baseline hazard
- **Download Command**:
```bash
gsutil -m cp -r gs://gfd_v1_4 ./local_directory
```
- **Web Portal**: http://global-flood-database.cloudtostreet.info/[3][4][5]

**Note**: This is an observed flood event database rather than modeled hazard scenarios, so it differs from baseline hazard mapping.[6][3]

**Google Earth Engine**: `GLOBAL_FLOOD_DB/MODIS_EVENTS/V1`[6]

## Microsoft Planetary Computer - Deltares Floods

**API Access**: Available via STAC API at `https://planetarycomputer.microsoft.com/api/stac/v1`[7]

**Collection ID**: `deltares-floods`

**Format**: NetCDF (not GeoTIFF), 90m resolution

**Coverage**: Global coastal flood maps (not riverine)[8][9][7]

**Python Access Example:**
```python
import pystac_client
catalog = pystac_client.Client.open(
    "https://planetarycomputer.microsoft.com/api/stac/v1"
)
search = catalog.search(
    collections=["deltares-floods"],
    query={"deltares:return_period": {"eq": 100}}
)
```

**License**: Open access with attribution required[8][7]

## Copernicus GLOFAS

**Coverage**: Global 100-year return period flood hazard maps at 100m resolution[10]

**Access Method**: Registered users only via password-protected OGC service[11][10]

**Request Access**: info@globalfloods.eu[11]

**Data Format**: Available through WMS-T (Web Map Service), FTP (on request), or ECMWF MARS archive[11]

**Note**: No direct public download URL; requires registration and tailored data requests.[10][11]

## FATHOM Global Flood Maps

**Access**: Commercial/requires paid account[12][13][14]

**Format**: GeoTIFF available through Fathom API

**Resolution**: ~30 meters (1 arc-second) globally, 10m where regional data permits[14]

**Coverage**: Fluvial, pluvial, and coastal flooding with 100-year return period available[14]

**Request Account**: https://www.fathom.global/fathom-jacobs-licence/[12]

**Not available on AWS Open Data or as free download**.[14]

## File Sizes and Specifications

**WRI Aqueduct**: Individual global tiles vary but expect 500MB-2GB per return period scenario for riverine flooding.[15][1]

**Global Flood Database**: Full database is several GB; individual event maps are typically 50-500MB.[4][3]

## Summary Recommendation

For **immediate curl/wget download** of 100-year riverine flood baseline data, use the **WRI Aqueduct S3 bucket**. For **programmatic access**, leverage **Google Earth Engine** with the WRI dataset. The **Global Flood Database** provides observed events rather than baseline hazards. **FATHOM** offers highest resolution but requires paid access, while **GLOFAS** requires registration but is free.[1][3][10][2]
