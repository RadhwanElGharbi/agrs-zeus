## Detailed Implementation Guide

### TIER 1 IMPLEMENTATION (Immediate - Week 1-2)

#### 1. WDPA Protected Areas
**Access Method:** Protected Planet API + Bulk Download[5][6]

**Steps:**
1. Register for API token at protectedplanet.net (5 min)[5]
2. **Option A - API (Recommended for dynamic updates):**
   ```python
   # Python implementation
   import requests
   
   TOKEN = "your_api_token"
   # Get Italy protected areas
   url = f"https://api.protectedplanet.net/v3/protected_areas/search?q=Italy&token={TOKEN}"
   response = requests.get(url)
   
   # Or use wdpar R package
   # library(wdpar)
   # italy_pa <- wdpa_fetch("Italy", wait=TRUE)
   ```
3. **Option B - Bulk Download (Faster initial setup):**
   - Visit protectedplanet.net/en/thematic-areas/wdpa[7]
   - Filter by Italy → Download shapefile (150-300 MB)[8][7]
4. Import to ArcGIS as new layer in SAIPEM_ALL.gpkg (1 hour)[2]
5. **Cost Weight Assignment:** Protected areas = 100-1000x multiplier or absolute exclusion zones[9][1]

**Attributes to Extract:** WDPA_PID, NAME, DESIG_ENG, IUCN_CAT, STATUS, REP_AREA[10][8]

**Alternative:** Google Earth Engine has WDPA integrated - can query via Python earthengine-api[11]

---

#### 2. Natura 2000 Sites
**Access Method:** EEA Direct Download + WMS/WFS Services[12][13]

**Steps:**
1. Download latest version (End 2023) from eea.europa.eu[13][12]
   - **Shapefile format:** Direct download (~500 MB for EU, filter Italy)[12][13]
   - **GeoPackage format:** Available as alternative[13][12]
2. **WFS Service (for automated updates):**
   ```
   WFS URL: Check EEA data portal for current endpoint
   Service: OGC:WFS
   Layer: Natura 2000 sites
   Filter: COUNTRY = 'IT'
   ```
3. Import and merge with WDPA layer or keep separate (3 hours)[2]
4. **Cost Weight:** Natura 2000 = 50-500x multiplier (requires environmental impact assessment)[14][1]

**Attributes:** SITECODE, SITENAME, SITETYPE (SPA/SAC/SCI), AREA_HA[15][12]

---

#### 3. Enhanced OSM Waterways with Width Attributes
**Access Method:** Overpass API[16][17]

**Steps:**
1. Use Overpass Turbo (overpass-turbo.eu) or direct API calls[17][16]
2. **Query for Italy waterways with width tags:**
   ```
   [out:json][timeout:300];
   area["ISO3166-1"="IT"]->.searchArea;
   (
     way["waterway"](area.searchArea);
     relation["waterway"](area.searchArea);
   );
   out geom;
   ```
3. **Extract critical attributes:**[18][19]
   - `waterway=river|stream|canal`
   - `width=* (meters)`
   - `name=*`
   - `intermittent=yes|no`
   - `tunnel=yes` (culverted sections)
4. **Attribute Enhancement (manual enrichment):**[18]
   - Where OSM width missing, estimate from waterway type:
     - stream: 1-3m → $15K open cut crossing
     - river (small): 3-10m → $50K open cut
     - river (medium): 10-50m → $250K HDD
     - river (major): >50m → $800K+ HDD
5. **Python processing script (osmdata library):**[20][21]
   ```python
   import osmium
   import geopandas as gpd
   
   # Parse OSM PBF file for Italy
   # Add width classification logic
   # Export enhanced waterways.gpkg
   ```
6. Replace existing waterways layer in SAIPEM_ALL.gpkg (6 hours total)[22]

**Cost Matrix Integration:** Create lookup table: `crossing_cost = f(width, method, angle)`[19][18]

#### 4. Italy Seismic Hazard Maps (INGV)
**Access Method:** WMS/WFS + Story Map Downloads[23][24][25]

**Steps:**
1. Access INGV Seismic Hazard Model MPS04-S1[24][25]
   - **Interactive Map:** esse1-gis.mi.ingv.it/mps04_eng.jsp[25]
   - **Data Access:** Download grid point values for PGA (Peak Ground Acceleration)[25]
2. **WFS Service (if available):**
   ```
   WFS Endpoint: Check INGV geoserver
   Layer: Seismic zones / PGA values
   Format: GeoTIFF or shapefile
   ```
3. **Manual Download Option:**
   - Navigate to INGV hazard maps section[26]
   - Download seismic zone classifications (Zones 1-4)[27][24]
4. Rasterize to match your 10m DEM resolution or keep as vector zones (4 hours)[27]
5. **Cost Weight:** Zone 1 (highest seismic) = 1.5-2x construction cost for reinforced pipe design[28][27]

**Alternative Source:** CFTIlandslides dataset has earthquake-induced landslide data with WFS[23]
- WFS: cfti.ingv.it/geoserver/CFTIlandslides/wfs[23]

### TIER 2 IMPLEMENTATION (Weeks 3-4)

#### 5. IUCN Red List Species Habitat Ranges
**Access Method:** Manual Download (No Public API)[29][30]

**Steps:**
1. Register at iucnredlist.org (free account)[29]
2. Navigate to Spatial Data Download section[29]
3. **Download Options:**[31][29]
   - **Taxonomic Groups:** Mammals, Birds, Amphibians, Reptiles (separate downloads)
   - **Format:** Shapefile (polygons) + CSV (points)
   - **Coverage:** Europe or Global (Italy subset post-processing)
4. Filter spatially to Italy bounding box (8 hours processing)[32][33]
5. **Priority Species for Pipelines:**[33][32]
   - Threatened mammals (lynx, brown bear, wolf)
   - Migratory birds (wetland species)
   - Amphibians (wetland indicators)
6. **Cost Weight:** Critical habitat (CR/EN species) = 500-1000x or complete exclusion[32][1]

**Note:** Data updated annually, no real-time API—manual re-download required[30]

#### 6. Italy Landslide Database (IFFI - Inventario Fenomeni Franosi)
**Access Method:** ISPRA WFS Service + Download[34][28][23]

**Steps:**
1. Access ISPRA Landslide Portal: idrogeo.isprambiente.it[28][34]
2. **Download Options:**
   - Shapefile/GeoPackage (direct download)
   - WFS Service for programmatic access
3. **Key Attributes:**[34][28]
   - Landslide type (slide, flow, topple, fall)
   - Activity status (active, dormant, stabilized)
   - Depth and volume estimates
4. Create landslide susceptibility raster (high/medium/low zones) (6 hours)[28][34]
5. **Cost Weight:**[35][34]
   - Active landslide zones: 10x cost (requires stabilization)
   - High susceptibility: 3-5x cost (geotechnical surveys + monitoring)
   - Medium susceptibility: 1.5-2x cost

**Integration:** Overlay with slope analysis from DEM for comprehensive geohazard layer[36][34]

#### 8. Enhanced OSM Roads and Railways
**Access Method:** Overpass API with Attribute Extraction[16][17]

**Steps:**
1. **Roads Query with Highway Classification:**[19]
   ```
   [out:json];
   area["ISO3166-1"="IT"];
   way["highway"~"motorway|trunk|primary|secondary"](area);
   out geom;
   ```
2. **Extract Attributes:**[19]
   - `highway=motorway|trunk|primary|secondary|tertiary|residential`
   - `lanes=*`
   - `surface=*`
   - `ref=* (road number)`
3. **Railways Query:**[37][19]
   ```
   way["railway"="rail"](area);
   ```
4. **Extract Railway Attributes:**
   - `railway=rail|light_rail|subway`
   - `usage=main|branch|industrial`
   - `gauge=* (track gauge)`
   - `electrified=yes|no`
   - `tracks=* (number)`
5. **Crossing Cost Matrix (8 hours to build):**[37][19]
   - Motorway: $400K-$600K (HDD required)
   - Primary road: $200K-$350K
   - Secondary road: $100K-$200K
   - Railway (main): $800K-$1.2M (extensive coordination)
   - Railway (branch): $500K-$800K

**Enhancement:** Add traffic volume estimates from external sources if available[19]

- **Cost:** Free but requires formal requests and processing time
- **Implementation:** 40+ hours (manual compilation)

- Area (hectares)

- Urban parcels: 5-10x acquisition cost vs rural
- Commercial: 8-15x vs agricultural
- Public lands: Simplified permitting but longer timelines

#### 10. Population Density for Class Location Analysis
**Access Method:** WorldPop or LandScan Downloads[42][43]

**Steps:**
1. **WorldPop (Recommended):**
   - URL: worldpop.org
   - Download Italy population density raster (100m resolution)
   - Free, updated annually
2. **Alternative - LandScan:**
   - Higher resolution (1km) but registration required
3. **Processing (6 hours):**
   - Calculate population density per grid cell
   - Classify ASME B31.8 Class Locations:[43][42]
     - Class 1: <10 buildings per mile
     - Class 2: 10-46 buildings per mile
     - Class 3: >46 buildings per mile
     - Class 4: Multi-story buildings
4. **Cost Impact:** Class 3/4 areas require thicker pipe (20-40% material cost increase)[42][43]
