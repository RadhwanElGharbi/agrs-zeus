# GIS Datasets for Oil & Gas Pipeline Routing in Bahrain

## 1. ELEVATION/TERRAIN (DEM)

### National High-Resolution DEMs

**DEM-2.5 (Derived from National Topographic Maps)**
- **Source/Provider**: Survey and Land Registration Bureau (SLRB)
- **Resolution/Scale**: 2.5m resolution, derived from 1:5,000 topographic contour maps
- **Temporal Coverage**: Based on national mapping program (ongoing updates)
- **Update Frequency**: Updated through as-built surveys and UAV captures
- **Access Type**: Restricted - requires formal request from SLRB
- **API Availability**: No public API
- **Official URL**: https://www.slrb.gov.bh/en/
- **Quality Assessment**: Excellent accuracy (±0.55m RMSE), best available for Bahrain; derived from high-quality national topographic mapping at 1:1,000 base scale with 137 surface feature types[1][2]

**DEM-5 (Derived from National Topographic Maps)**
- **Source/Provider**: Survey and Land Registration Bureau (SLRB)
- **Resolution/Scale**: 5m resolution, derived from 1:25,000 topographic contour maps
- **Temporal Coverage**: Historical national mapping
- **Update Frequency**: Periodic updates
- **Access Type**: Restricted - requires formal request from SLRB
- **API Availability**: No public API
- **Official URL**: https://www.slrb.gov.bh/en/
- **Quality Assessment**: Very good accuracy (±1.0m RMSE); suitable for regional analysis[2]

### Regional/Global High-Resolution DEMs

**Copernicus DEM (GLO-30)**
- **Source/Provider**: European Space Agency / Copernicus Programme
- **Resolution/Scale**: 30m resolution
- **Temporal Coverage**: 2010-2015 (based on TanDEM-X/WorldDEM)
- **Update Frequency**: Static product (no regular updates planned)
- **Access Type**: Open/Free
- **API Availability**: Yes - via Copernicus Data Space Ecosystem API
- **Official URL**: https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM
- **Quality Assessment**: Superior accuracy to SRTM and ASTER; RMSE typically 5-6m; best global DEM for Bahrain; Digital Surface Model including buildings/vegetation[3][4]

**Copernicus DEM (GLO-90)**
- **Source/Provider**: European Space Agency / Copernicus Programme
- **Resolution/Scale**: 90m resolution
- **Temporal Coverage**: 2010-2015
- **Update Frequency**: Static product
- **Access Type**: Open/Free
- **API Availability**: Yes - via Copernicus Data Space Ecosystem API
- **Official URL**: https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM
- **Quality Assessment**: Good for regional analysis; lower resolution alternative to GLO-30[4]

**SRTM Version 4.1**
- **Source/Provider**: NASA/USGS
- **Resolution/Scale**: 30m resolution (1 arc-second)
- **Temporal Coverage**: February 2000 (single acquisition)
- **Update Frequency**: Static (historical dataset)
- **Access Type**: Open/Free
- **API Availability**: Yes - USGS Earth Explorer API
- **Official URL**: https://earthexplorer.usgs.gov/
- **Quality Assessment**: Moderate accuracy (±6-10m RMSE for Bahrain); widely used legacy dataset but superseded by Copernicus DEM; void-filled version available[2][3]

**ASTER GDEM Version 3**
- **Source/Provider**: NASA/METI (Japan)
- **Resolution/Scale**: 30m resolution (1 arc-second)
- **Temporal Coverage**: 2000-2013 composite
- **Update Frequency**: Static (Version 3 released 2019)
- **Access Type**: Open/Free
- **API Availability**: Yes - NASA Earthdata API
- **Official URL**: https://earthdata.nasa.gov/
- **Quality Assessment**: Lower accuracy than SRTM and Copernicus DEM; significant artifacts and noise; not recommended for precision pipeline routing[3][2]

## 2. LAND COVER / LAND USE

### National Land Use Maps

**Bahrain Spatial Data Infrastructure (BSDI) Land Use Layers**
- **Source/Provider**: Central Informatics Organisation (CIO) - GIS Directorate
- **Resolution/Scale**: Vector data derived from 1:1,000 national mapping
- **Temporal Coverage**: Current (regularly updated)
- **Update Frequency**: Continuous updates through as-built surveys
- **Access Type**: Restricted - available to government agencies and authorized organizations (30+ organizations currently use BSDI)
- **API Availability**: No public API (internal government portal only)
- **Official URL**: www.bsdi.gov.bh (government intranet)
- **Quality Assessment**: Highest quality national land use data; includes detailed urban development, agricultural areas (palm groves), and infrastructure classifications[5][6][7]

### Global Land Cover Products

**ESA WorldCover 2021**
- **Source/Provider**: European Space Agency (ESA WorldCover Consortium)
- **Resolution/Scale**: 10m resolution
- **Temporal Coverage**: 2021 (2020 version also available)
- **Update Frequency**: Annual updates planned
- **Access Type**: Open/Free (CC-BY-4.0 license)
- **API Availability**: Yes - WMS/WMTS services, Google Earth Engine API
- **Official URL**: https://esa-worldcover.org / https://worldcover2021.esa.int/download
- **Quality Assessment**: Excellent quality with 11 land cover classes; highest resolution global land cover product; derived from Sentinel-1 radar and Sentinel-2 optical data; highly accurate for Bahrain's desert and urban environments[8][9][10][11]

**Esri Sentinel-2 Land Use/Land Cover (10m Global)**
- **Source/Provider**: Esri / Impact Observatory
- **Resolution/Scale**: 10m resolution
- **Temporal Coverage**: Annual time series (2017-present)
- **Update Frequency**: Annual
- **Access Type**: Free for non-commercial use
- **API Availability**: Yes - ArcGIS Living Atlas API
- **Official URL**: https://livingatlas.arcgis.com/landcoverexplorer/
- **Quality Assessment**: Good temporal continuity; useful for change detection; 9-class system; complementary to ESA WorldCover[12][13]

**Google Dynamic World (Sentinel-2 Based)**
- **Source/Provider**: Google / World Resources Institute
- **Resolution/Scale**: 10m resolution
- **Temporal Coverage**: 2015-present (near-real-time)
- **Update Frequency**: Every 2-5 days (Sentinel-2 revisit)
- **Access Type**: Open/Free
- **API Availability**: Yes - Google Earth Engine API only
- **Official URL**: https://www.dynamicworld.app/
- **Quality Assessment**: Near-real-time land cover with probability scores for each class; excellent for monitoring rapid development; requires Google Earth Engine access[11]

## 3. HYDROLOGY / WATER

### National Water Resources Data

**Ministry of Oil - Water Resources Management Unit Data**
- **Source/Provider**: Water Resources Management (WRM) Unit, Ministry of Oil
- **Resolution/Scale**: National scale groundwater and desalination infrastructure
- **Temporal Coverage**: Current operational data
- **Update Frequency**: Continuous monitoring
- **Access Type**: Restricted - government/research institutions only
- **API Availability**: No public API
- **Official URL**: Contact through Ministry of Oil
- **Quality Assessment**: Comprehensive data on Dammam aquifer, desalination plants, and treated wastewater systems; critical for pipeline routing due to water infrastructure conflicts[14][15]

**Bahrain Note on Surface Water**
- **Source/Provider**: National environmental agencies
- **Key Information**: Bahrain has NO rivers, perennial streams, lakes, or dams; total annual surface runoff only 4 million m³; drainage is endoreic (internal basins); wadis are ephemeral
- **Quality Assessment**: Any "hydrography" data for Bahrain is limited to wadis (dry valleys), coastal features, and man-made water infrastructure (pipelines, treatment plants)[15][16]

**BSDI Water Infrastructure Layers**
- **Source/Provider**: Central Informatics Organisation - BSDI Portal
- **Resolution/Scale**: Vector data (precise infrastructure locations)
- **Temporal Coverage**: Current
- **Update Frequency**: Continuous
- **Access Type**: Restricted to authorized organizations
- **API Availability**: No public API
- **Official URL**: www.bsdi.gov.bh
- **Quality Assessment**: Detailed water transmission and distribution networks; sewerage and drainage infrastructure; essential for pipeline routing conflict avoidance[6][7]

### Global Hydrology Datasets

**Global Surface Water Explorer (JRC)**
- **Source/Provider**: European Commission Joint Research Centre
- **Resolution/Scale**: 30m resolution
- **Temporal Coverage**: 1984-2021
- **Update Frequency**: Annual updates
- **Access Type**: Open/Free
- **API Availability**: Yes - Google Earth Engine
- **Official URL**: https://global-surface-water.appspot.com/
- **Quality Assessment**: Limited relevance for Bahrain given absence of natural surface water bodies; useful for coastal areas, sabkhas (salt flats), and Tubli Bay wetlands[16]

**HydroSHEDS (Hydrological data and maps based on SHuttle Elevation Derivatives at multiple Scales)**
- **Source/Provider**: WWF / USGS
- **Resolution/Scale**: 15 arc-second (~500m)
- **Temporal Coverage**: Based on SRTM 2000
- **Update Frequency**: Static
- **Access Type**: Open/Free
- **API Availability**: No dedicated API
- **Official URL**: https://www.hydrosheds.org/
- **Quality Assessment**: Very limited utility for Bahrain due to lack of drainage networks; main use is for wadi delineation and terrain analysis[17]

- **Access Type**: Restricted - available to government agencies and authorized private organizations
- **API Availability**: No public API (internal BSDI portal access only)
- **Official URL**: www.bsdi.gov.bh / https://www.bahrain.bh/wps/portal/en/BNP/ExploreBahrain/GeographicInformationSystems
- **Quality Assessment**: Highest quality and most current road data for Bahrain; includes street names, addresses, classification (motorways, primary, secondary roads), turn restrictions, lanes, surface types, one-way streets; maintained through integration with Ministry of Transportation and Traffic systems[7][5][6][1]

**Ministry of Transportation and Telecommunications (MTT) Road Data**
- **Source/Provider**: General Directorate of Traffic / MTT
- **Resolution/Scale**: Operational road network data

- **Update Frequency**: Continuous (integrated with traffic management systems)

- **API Availability**: Limited API through MyGov application for traffic services
- **Official URL**: https://www.mtt.gov.bh/
- **Quality Assessment**: Official source for road classifications, traffic regulations, and construction updates; integrates with BSDI[18]

**Bahrain Open Data Portal - Road Network Length**
- **Source/Provider**: Information & eGovernment Authority
- **Resolution/Scale**: Statistical data (surfaced roads: 4,543 km; unsurfaced: 730 km as of 2022)
- **Temporal Coverage**: 2021-2022
- **Update Frequency**: Annual
- **Access Type**: Open/Free
- **API Availability**: Yes - CKAN-based API

### OpenStreetMap (OSM)

**OpenStreetMap Bahrain Roads**
- **Source/Provider**: OpenStreetMap Foundation / Community contributors / Kaart ground survey (2017)
- **Resolution/Scale**: Variable (street-level detail)
- **Temporal Coverage**: Current (continuously updated since 2007, major ground survey 2017)

## 7. INFRASTRUCTURE - PIPELINES

### National Oil & Gas Pipeline Data

**BSDI Gas & Oil Pipelines Layer**
- **Source/Provider**: Central Informatics Organisation / Bahrain Petroleum Company (BAPCO) / nogaholding
- **Resolution/Scale**: Vector data with precise pipeline locations
- **Temporal Coverage**: Current
- **Update Frequency**: Continuous updates from operators and as-built surveys
- **Access Type**: Restricted - highly sensitive infrastructure data; available only to authorized government agencies and oil/gas operators
- **API Availability**: No public API
- **Official URL**: www.bsdi.gov.bh (requires authorization)
- **Quality Assessment**: Most comprehensive and accurate pipeline data for Bahrain; includes oil, gas, and refined product pipelines; essential for routing to avoid existing infrastructure; includes BAPCO operational pipelines and international connections[1][6][7]

**BAPCO (Bahrain Petroleum Company) Pipeline Infrastructure Data**
- **Source/Provider**: BAPCO Energies / nogaholding
- **Resolution/Scale**: Engineering-grade precision (as-built drawings)
- **Temporal Coverage**: Current operational pipelines
- **Update Frequency**: Updated with new construction and modifications
- **Access Type**: Highly restricted - only available through formal agreements with BAPCO/nogaholding
- **API Availability**: No public API
- **Official URL**: https://www.bapcoenergies.com/ (contact for data access)
- **Quality Assessment**: Authoritative source for oil and gas pipeline locations; includes AB4 crude oil pipeline (118 km, 30-inch, 400,000 bpd capacity connecting Sitra Refinery to Saudi Aramco's Abqaiq plant); critical for conflict avoidance in new pipeline routing[23][24][25]

**AB4 Pipeline (Bahrain-Saudi Arabia)**
- **Source/Provider**: BAPCO / Saudi Aramco
- **Specifications**: 118 km length, 30-inch diameter, 400,000 bpd capacity; 73 km onshore (Saudi Arabia), 45 km offshore (Gulf crossing)
- **Temporal Coverage**: Operational since November 2018
- **Access Type**: Restricted
- **Quality Assessment**: Major international crude oil pipeline; replaced older 230,000 bpd link; must be considered in routing analysis for setback requirements[24][23]

**OpenStreetMap Pipelines**
- **Source/Provider**: OpenStreetMap community
- **Resolution/Scale**: Variable (incomplete)
- **Temporal Coverage**: Partial coverage
- **Update Frequency**: Sporadic crowdsourced updates
- **Access Type**: Open/Free
- **API Availability**: Yes - Overpass API
- **Official URL**: https://www.openstreetmap.org/
- **Quality Assessment**: INCOMPLETE and UNRELIABLE for Bahrain; pipeline infrastructure is security-sensitive and not comprehensively mapped in OSM; NOT suitable for pipeline routing decisions; use only for general context with verification required[7]

## 8. PROTECTED AREAS / ENVIRONMENTAL

### National Protected Areas

**Ministry of Municipalities Affairs & Agriculture - Protected Areas Registry**
- **Source/Provider**: Supreme Council for Environment / Ministry of Municipalities Affairs & Agriculture
- **Resolution/Scale**: Vector polygon data
- **Temporal Coverage**: Current (established 1995-1997)
- **Update Frequency**: Periodic updates as designations change
- **Access Type**: Restricted - request from environmental authorities; some data in BSDI
- **API Availability**: No public API
- **Official URL**: https://www.bahrain.bh/ (environmental sections)
- **Quality Assessment**: Authoritative national source; 6 designated protected areas (1 terrestrial, 5 marine); includes boundaries and management zones[26][27][28]

**Al Areen Wildlife Park and Reserve**
- **Details**: 5.4 km² terrestrial protected area; established 1975; desert environment conservation
- **Status**: Law-designated protected area; restricted access except for researchers
- **Relevance**: Critical constraint for pipeline routing in western-central Bahrain[27][26]

**Tubli Bay Protected Area**
- **Details**: Marine protected area; Ramsar wetland (designated 1997); mangrove habitat
- **Status**: Law No. 53 of 2006
- **Relevance**: Northeastern Bahrain; coastal pipeline routing constraint[26]

**Hawar Islands Protected Area**
- **Details**: 5,200+ ha archipelago; Ramsar site No. 920; seabird breeding habitat (Socotra Cormorant); dugong and sea turtle habitat
- **Status**: Gazetted 1997; state-owned; military restricted access
- **Relevance**: Southern offshore area; submarine pipeline routing constraint[28]

### Global Protected Areas Database

**World Database on Protected Areas (WDPA)**
- **Source/Provider**: UN Environment Programme World Conservation Monitoring Centre (UNEP-WCMC) / IUCN
- **Resolution/Scale**: Vector polygons
- **Temporal Coverage**: Current (monthly updates)
- **Update Frequency**: Monthly
- **Access Type**: Open/Free
- **API Availability**: Yes - Protected Planet API
- **Official URL**: https://www.protectedplanet.net/country/BHR
- **Quality Assessment**: Good global coverage; 7 protected areas mapped for Bahrain; includes Najwat Bul Thamah, Hayr Bul Thamah, Al-Areen, Tubli Bay, Hawar Islands, and others; generally accurate but verify boundaries with national sources for pipeline routing; includes IUCN categories and designations (Ramsar, national parks)[29][30][28]

## 10. CLIMATE / WEATHER

### National Meteorological Data

**Bahrain Meteorological Directorate (Civil Aviation Affairs)**
- **Source/Provider**: Meteorological Directorate, Civil Aviation Affairs
- **Resolution/Scale**: Point stations and national forecasts
- **Temporal Coverage**: Historical records (1950s-present) and real-time data
- **Update Frequency**: Real-time observations, daily forecasts
- **Access Type**: Some data publicly available; detailed data requires request
- **API Availability**: Limited web services
- **Official URL**: Contact through Civil Aviation Affairs
- **Quality Assessment**: Official national source; includes temperature, rainfall (average ~70mm/year), humidity, wind, sandstorms; essential for pipeline design parameters (extreme temperatures, corrosion rates); arid climate data critical[37][15]

### Global Climate Datasets

**ERA5 Reanalysis (ECMWF)**
- **Source/Provider**: European Centre for Medium-Range Weather Forecasts (ECMWF) / Copernicus Climate Change Service
- **Resolution/Scale**: 31 km grid (0.25° x 0.25°), 137 vertical levels
- **Temporal Coverage**: January 1940-present (1991-2020 current climatology)
- **Update Frequency**: Continuous (hourly data with ~5-day lag)
- **Access Type**: Open/Free
- **API Availability**: Yes - CDS API (Climate Data Store)
- **Official URL**: https://cds.climate.copernicus.eu/ | https://climateknowledgeportal.worldbank.org/country/bahrain/era5-historical
- **Quality Assessment**: Excellent quality reanalysis; hourly atmospheric, land, and ocean variables; best available global climate dataset; includes temperature, precipitation, wind speed/direction, solar radiation, humidity; critical for pipeline thermal design and environmental assessment; 95% confidence with validation points[38][39][40][41]

**WorldClim Version 2.1**
- **Source/Provider**: WorldClim / University of California
- **Resolution/Scale**: 30 arc-second to 2.5 arc-minute (~1km to ~5km)
- **Temporal Coverage**: 1970-2000 baseline; future scenarios available
- **Update Frequency**: Static baseline (periodic version updates)
- **Access Type**: Open/Free
- **API Availability**: No - direct download only
- **Official URL**: https://www.worldclim.org/
- **Quality Assessment**: Good for climatology baseline; monthly temperature and precipitation averages; bioclimatic variables useful for environmental assessment; coarser temporal resolution than ERA5[38]

**Copernicus Climate Change Service (C3S) Data**
- **Source/Provider**: ECMWF / Copernicus
- **Resolution/Scale**: Variable (multiple products)
- **Temporal Coverage**: Historical and forecasts
- **Update Frequency**: Continuous
- **Access Type**: Open/Free
- **API Availability**: Yes - CDS API
- **Official URL**: https://climate.copernicus.eu/
- **Quality Assessment**: Comprehensive climate data portal; includes ERA5, seasonal forecasts, climate projections; excellent resource for environmental impact assessment[39]

- **Quality Assessment**: High-resolution population distribution; country totals adjusted to match UN estimates; excellent for pipeline routing to minimize population exposure; includes age-sex demographics; 100m resolution suitable for detailed analysis; widely used for infrastructure planning[45][46][47][48]

**LandScan Global Population**
- **Source/Provider**: Oak Ridge National Laboratory (ORNL) / US Department of Energy
- **Resolution/Scale**: 30 arc-second (~1km at equator)
- **Temporal Coverage**: Annual products (2000-present)
- **Update Frequency**: Annual
- **Access Type**: Free for US government and qualified users; commercial license available
- **API Availability**: No public API
- **Official URL**: https://landscan.ornl.gov/
- **Quality Assessment**: Ambient population distribution (24-hour average); accounts for daytime/nighttime population movement; slightly coarser than WorldPop but sophisticated methodology; good for risk assessment; licensing restrictions may apply[49][50][51]

**Gridded Population of the World (GPW) v4**
- **Source/Provider**: NASA SEDAC / Columbia University
- **Resolution/Scale**: 30 arc-second (~1km)
- **Temporal Coverage**: 2000, 2005, 2010, 2015, 2020
- **Update Frequency**: Every 5 years
- **Access Type**: Open/Free
- **API Availability**: NASA SEDAC API
- **Official URL**: https://sedac.ciesin.columbia.edu/data/collection/gpw-v4
- **Quality Assessment**: Census-based population distribution; lower resolution than WorldPop; suitable for regional context[51]

## 13. SATELLITE IMAGERY

### Free/Open Imagery

**Sentinel-2 (Copernicus Programme)**
- **Source/Provider**: European Space Agency (ESA) / Copernicus Programme
- **Resolution/Scale**: 10m (visible/NIR bands), 20m (red edge/SWIR), 60m (atmospheric bands)
- **Temporal Coverage**: 2015-present
- **Update Frequency**: 5-day revisit (2 satellites: Sentinel-2A and 2B)
- **Access Type**: Open/Free
- **API Availability**: Yes - Copernicus Open Access Hub API, Google Earth Engine, AWS S3
- **Official URL**: https://dataspace.copernicus.eu/ | https://scihub.copernicus.eu/
- **Quality Assessment**: Excellent free baseline imagery; 13 spectral bands; suitable for land cover mapping, vegetation analysis, change detection, and initial routing studies; multispectral capabilities useful for identifying land features; 10m resolution adequate for corridor-level planning; atmospheric correction available[52][53]

### Commercial High-Resolution Imagery

**Maxar (WorldView, GeoEye)**
- **Source/Provider**: Maxar Technologies
- **Resolution/Scale**: 30-50 cm (WorldView-3/4), 50 cm (WorldView-2), 46 cm (GeoEye-1)
- **Temporal Coverage**: Archive from 2008-present; tasking for new imagery
- **Update Frequency**: On-demand tasking; archive refresh varies
- **Access Type**: Commercial license required
- **API Availability**: Yes - Maxar SecureWatch API, ARD API
- **Official URL**: https://www.maxar.com/products/imagery
- **Quality Assessment**: Highest resolution commercial imagery available; excellent for detailed pipeline routing, engineering surveys, as-built verification, and obstruction identification; multispectral and panchromatic; sub-meter accuracy with orthorectification; preferred for final route optimization and permitting; costly but industry standard[54]

**Airbus Defence and Space (Pléiades, SPOT)**
- **Source/Provider**: Airbus Defence and Space
- **Resolution/Scale**: 50 cm (Pléiades Neo, Pléiades), 1.5m (SPOT 6/7)
- **Temporal Coverage**: Archive from 2011-present; tasking available
- **Update Frequency**: On-demand tasking
- **Access Type**: Commercial license required
- **API Availability**: Yes - OneAtlas API
- **Official URL**: https://www.intelligence-airbusds.com/ | https://space-solutions.airbus.com/
- **Quality Assessment**: Very high quality; competitive with Maxar; Pléiades Neo constellation (4 satellites) provides 50cm resolution; excellent for detailed engineering; good alternative to Maxar with strong coverage in Middle East[55][54]

**Planet Labs (SkySat, PlanetScope)**
- **Source/Provider**: Planet Labs
- **Resolution/Scale**: 50 cm (SkySat), 3m (PlanetScope)
- **Temporal Coverage**: 2016-present (daily global coverage with PlanetScope)
- **Update Frequency**: Daily revisit (PlanetScope constellation of 200+ satellites); SkySat tasking
- **Access Type**: Commercial subscription required
- **API Availability**: Yes - Planet API
- **Official URL**: https://www.planet.com/
- **Quality Assessment**: Unique value proposition of daily monitoring at 3m resolution; SkySat provides 50cm when needed; excellent for construction monitoring, change detection, and security; more affordable than Maxar/Airbus for frequent monitoring; daily coverage useful for tracking development along corridor[54]

## 14. SPECIAL DATASETS FOR BAHRAIN

### Archaeological and Cultural Heritage Sites

**UNESCO World Heritage Sites - Bahrain**
- **Source/Provider**: UNESCO World Heritage Centre / Bahrain Authority for Culture and Antiquities
- **Key Sites**: 
  - Qal'at al-Bahrain (Ancient Harbour and Capital of Dilmun) - inscribed 2005
  - Pearling, Testimony of an Island Economy (Muharraq heritage buildings) - inscribed 2012
  - Dilmun Burial Mounds (12,000+ burial mounds) - inscribed 2019
- **Resolution/Scale**: Site boundaries with buffer zones
- **Temporal Coverage**: Current (protected sites)
- **Update Frequency**: Updated with new inscriptions and boundary modifications
- **Access Type**: Publicly documented; detailed boundaries require SLRB/heritage authority
- **API Availability**: UNESCO World Heritage API (limited spatial data)
- **Official URL**: https://whc.unesco.org/ | Bahrain Authority for Culture and Antiquities
- **Quality Assessment**: Critical constraint for pipeline routing; legally protected with buffer zones; Qal'at al-Bahrain has sea channel buffer; burial mounds scattered across northern Bahrain (types: A, B, C, D, E indicating chronology and social hierarchy); Saar Archaeological Site (2050-1750 BC settlement); archaeological significance requires major routing diversions; requires archaeological impact assessment for projects[56][57][58]

**Bahrain Authority for Culture and Antiquities - Archaeological Sites Register**
- **Source/Provider**: Bahrain Authority for Culture and Antiquities (BACA)
- **Coverage**: Comprehensive registry beyond World Heritage sites
- **Access Type**: Restricted - requires consultation with BACA for project planning
- **Quality Assessment**: Essential for pipeline routing; thousands of archaeological sites including burial mounds, tells, settlement sites; rescue archaeology protocols required; consultation mandatory for infrastructure projects[58]

### Seismic and Geological Hazards

**Arabian Plate Seismicity - Regional Context**
- **Source/Provider**: USGS / Regional seismic networks
- **Assessment**: Bahrain has LOW seismic hazard; Arabian Plate interior is tectonically stable; nearest active seismicity is Zagros Mountains (Iran) ~500+ km away
- **Access Type**: Global seismic hazard maps freely available
- **Official URL**: https://earthquake.usgs.gov/
- **Quality Assessment**: Seismic design considerations minimal for Bahrain; regional seismic data adequate; no national seismic network or specific hazard maps needed for Bahrain[59]

**Sabkha (Salt Flat) Mapping**
- **Source/Provider**: BSDI / SLRB / 1975-76 Geological Survey
- **Description**: Extensive sabkhas (coastal and inland salt flats) in Bahrain; critical for pipeline engineering due to highly corrosive conditions, bearing capacity issues, and seasonal water table fluctuations
- **Coverage**: Mapped in 1:10,000 soil and geology surveys
- **Access Type**: Through BSDI or SLRB
- **Quality Assessment**: Essential for pipeline routing and corrosion protection design; sabkhas require specialized construction techniques; southwestern sabkha particularly extensive; gypsum-rich soils cause severe corrosion risk[32][31]

### Coastal and Marine Data

**Reclamation Projects and Artificial Islands**
- **Source/Provider**: SLRB / Ministry of Municipalities Affairs & Agriculture
- **Key Features**: Extensive land reclamation (Bahrain has grown significantly through reclamation); Durrat Al Bahrain (artificial archipelago); Northern coast strategic development
- **Temporal Coverage**: Ongoing (rapid development)
- **Update Frequency**: SLRB updates through as-built surveys and UAV mapping
- **Access Type**: Through BSDI and SLRB
- **Quality Assessment**: Critical for pipeline routing in coastal areas; reclaimed land has different geotechnical properties; frequent updates needed due to ongoing construction; Sentinel-2 imagery shows recent reclamation well; infrastructure placement on reclaimed land requires special design[53][57][52]

**Marine Charts and Bathymetry**
- **Source/Provider**: SLRB (hydrographic survey services) / Regional maritime authorities
- **Coverage**: Coastal waters and shallow Gulf areas
- **Access Type**: Maritime charts publicly available; detailed bathymetry may be restricted
- **Quality Assessment**: Important for submarine pipeline routes; Gulf waters generally shallow around Bahrain; AB4 pipeline route provides precedent for offshore construction[24][1]

### Military and Restricted Zones

**Military Installations and Restricted Airspace**
- **Source/Provider**: Bahrain Defence Force / Civil Aviation Affairs
- **Coverage**: Airbase visible in satellite imagery (northeastern Muharraq); restricted zones around Hawar Islands; maritime military zones
- **Access Type**: Restricted - formal permissions required
- **Quality Assessment**: Major constraint for pipeline routing; consultation with security authorities mandatory; some areas absolutely prohibited; visible in commercial satellite imagery but official boundaries require government consultation[52]

### Subsurface Utility Infrastructure (3D Mapping)

**SLRB 3D-Enabled Geospatial Data Model**
- **Source/Provider**: Survey and Land Registration Bureau (developed with Ordnance Survey UK)
- **Description**: First 3D-enabled geospatial data model for Bahrain; includes above and below-ground infrastructure
- **Resolution/Scale**: Object-based data model compliant with OGC and ISO standards
- **Temporal Coverage**: Current (ongoing National 3D Mapping programme)
- **Update Frequency**: Continuous updates
- **Access Type**: Restricted - SLRB and authorized users
- **API Availability**: Internal government use
- **Official URL**: https://www.slrb.gov.bh/
- **Quality Assessment**: Cutting-edge 3D data model specifically designed for utility infrastructure management; essential for pipeline routing to avoid conflicts with existing subsurface infrastructure; part of "digital twin" strategy for smart nation development; includes utility depth information critical for trenchless crossing design[60][34][1]

### Special Environmental Datasets

**Tubli Bay Ramsar Wetland Monitoring**
- **Source/Provider**: Supreme Council for Environment
- **Description**: Last remaining natural mangrove aggregation in Bahrain; critical bird habitat
- **Access Type**: Environmental authority consultation required
- **Quality Assessment**: Sensitive environmental area; pipeline routing near Tubli Bay requires comprehensive environmental impact assessment; seasonal water levels and ecology documented[26]

**Groundwater Salinity and Contamination Mapping**
- **Source/Provider**: Water Resources Management Unit / Ministry of Oil
- **Description**: Detailed mapping of Dammam aquifer salinization; four types identified: brackish water upflow, seawater intrusion (eastern region), sabkha water intrusion (southwestern), irrigation return flow
- **Access Type**: Research/government access
- **Quality Assessment**: Important for understanding soil corrosivity and contamination risks; groundwater over-extraction has caused widespread salinization; areas of influence mapped; relevant for cathodic protection design and leak detection planning[16]

## Summary Assessment

**Highest Priority National Datasets** (contact SLRB, CIO-BSDI, and relevant ministries):
1. BSDI Portal comprehensive infrastructure layers (300+ layers)
2. SLRB 2.5m DEM and 3D geospatial data model
3. BAPCO pipeline infrastructure data
4. Archaeological sites registry (BACA)
5. Protected areas boundaries
6. 1975-76 geological and soil maps (still relevant)

**Best Global Datasets for Bahrain**:
1. Copernicus DEM 30m (elevation)
2. ESA WorldCover 2021 10m (land cover)
3. ERA5 reanalysis (climate)
4. WorldPop 100m (population)
5. Sentinel-2 10m (imagery baseline)
6. WDPA (protected areas)

**Critical Gaps/Limitations**:
- Public access to national datasets severely restricted (security-sensitive infrastructure)
- OpenStreetMap incomplete for utilities and pipelines
- Rapid development means frequent updates essential
- Archaeological sites pervasive but not all publicly mapped
- Commercial imagery necessary for engineering-grade routing

**Recommended Data Access Strategy**:
1. Establish formal agreements with SLRB, CIO, and BAPCO for national infrastructure data access
2. Use global open datasets (Copernicus DEM, ESA WorldCover, ERA5, WorldPop) for initial corridor analysis
3. Acquire commercial high-resolution imagery (Maxar/Airbus) for detailed routing
4. Consult with Bahrain Authority for Culture and Antiquities for archaeological clearance
5. Verify all routing with BSDI Portal data through authorized access
