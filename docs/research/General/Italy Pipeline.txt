For existing pipeline data in Northeastern Italy (Veneto and Friuli Venezia Giulia regions), here are the primary sources:

## National/Commercial Sources

**Snam Atlas and Network Data**
Snam (Italy's national gas transmission operator) manages the primary gas pipeline network in Northeastern Italy, including the strategic Tarvisio entry point which historically was Italy's main entry for Russian gas. Access their data at:
- **Snam Atlas**: http://www.snamatlas.it - Interactive global gas infrastructure map with Italy coverage
- **Snam Network Statement**: https://www.snam.it/en/transportation/business-information/national-gas-pipeline-network.html - Geographic representation of the national network
- **Access**: Public viewing available online; detailed GIS datasets require formal request to Snam
- **Coverage**: Includes major transmission pipelines like Bordano-Istrana (120 km DN1400), Zimella-Cervignano (170 km), and Collalto storage field connections

**SINFI - Italian Underground Utilities Cadastre**
Italy's official underground infrastructure cadastre includes gas networks, but has limited public GIS access:
- **Coverage**: Gas pipelines, electric networks, water supply, telecommunications
- **Access**: Restricted - Started data collection in 2017, still building completeness
- **Status**: Public viewing in development; detailed data requires authorization from relevant authorities
- **Relevance**: Includes Friuli Venezia Giulia region gas networks under regional law LR 3/2011

## European/International Open Sources

**ENTSOG Transparency Platform**
European Network of Transmission System Operators for Gas provides operational data:
- **URL**: https://transparency.entsog.eu
- **Content**: Entry/exit points, operational flows, capacity data for Italy including Tarvisio
- **Access**: Open/Free with API available
- **Format**: Operational data rather than detailed spatial GIS; System Capacity Maps show pipeline routes graphically
- **Map Downloads**: https://www.entsog.eu/maps (System Capacity Map 2025 available)

**SciGRID_gas - European Gas Network Model**
Open-source gas transmission network model covering Europe including Italy:
- **URL**: https://zenodo.org/search?q=SciGRID_gas
- **Dataset**: IGGINL version contains ~206,000 km of European pipelines including Italy
- **Format**: GeoJSON and CSV files with pipeline geometry, diameter, capacity estimates
- **Access**: Open/Free - Creative Commons CC-BY-4.0 license
- **Quality**: Good coverage but parameters estimated from multiple sources; resolution suitable for regional analysis but may lack detailed local segments
- **Download**: Direct from Zenodo repository

**Global Energy Monitor - Global Gas Infrastructure Tracker**
Comprehensive global pipeline database:
- **URL**: https://globalenergymonitor.org/projects/global-gas-infrastructure-tracker/
- **Coverage**: Major Italian pipelines including TAP Interconnection, Trans-Mediterranean pipeline segments
- **Access**: Open/Free - Download requires form submission at https://globalenergymonitor.org/projects/global-gas-infrastructure-tracker/download-data/
- **Format**: Includes GIS shapefile format for pipeline routes
- **Quality**: Focuses on major transmission pipelines; may not include all regional distribution networks

## Regional Geoportals

**Veneto Region Geoportal**
- **URL**: https://idt2.regione.veneto.it
- **Content**: Regional infrastructure data including utilities
- **Download**: https://idt2.regione.veneto.it/idt/downloader/download
- **Access**: Open/Free for most datasets
- **Limitation**: Detailed utility infrastructure data may be restricted for security reasons

**Friuli Venezia Giulia IRDAT**
- **URL**: https://irdat.regione.fvg.it and https://eaglefvg.regione.fvg.it/eagle/main.aspx
- **Content**: Environmental and territorial data catalogue
- **Access**: Open access for many datasets; some require registration
- **Limitation**: Pipeline data specifically may not be fully public

**National Geoportal (Geoportale Nazionale)**
- **URL**: https://geodati.gov.it/geoportale/
- **Content**: National spatial data catalogue following INSPIRE directive
- **Access**: Discovery and viewing; download varies by dataset
- **Limitation**: Infrastructure data availability varies; security-sensitive data restricted

## OpenStreetMap (Limited Utility)

**OSM Pipeline Data**
- **URL**: https://www.openstreetmap.org
- **Access**: Open/Free via Overpass API
- **Quality Assessment**: Very incomplete for Italy's pipeline network - not recommended as primary source
- **Use**: Supplement only; security-sensitive infrastructure is poorly documented in OSM

## Recommended Approach for Northeastern Italy

1. **Start with ENTSOG System Capacity Map 2025** for overview of major transmission corridors
2. **Download SciGRID_gas IGGINL dataset** for open-source GIS-ready pipeline network
3. **Request detailed data from Snam** for authoritative national transmission network (requires formal business justification)
4. **Check Global Energy Monitor** for major project-level detail with documentation
5. **Consult regional geoportals** for supplementary infrastructure context
6. **Contact SINFI administrators** if detailed local distribution networks needed (requires authorization)

**Critical Note**: Detailed pipeline infrastructure data is security-sensitive in Italy. While overview maps and operational statistics are publicly available, high-resolution GIS datasets with precise locations often require formal requests demonstrating legitimate business need, particularly for active oil and gas transmission infrastructure. For pipeline routing projects, establishing relationships with Snam and relevant regional authorities will be essential for accessing comprehensive data.
