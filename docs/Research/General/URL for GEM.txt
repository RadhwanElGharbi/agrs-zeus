Based on the information gathered, here is the comprehensive download information for the GEM Global Seismic Hazard Map:

## Direct Download URL

**Primary Source - Zenodo:**
```
https://zenodo.org/records/8409647/files/GEM-GSHM_PGA-475y-rock_v2023.zip
```

This is the direct download URL for the Global PGA GeoTIFF raster with 475-year return period (10% probability of exceedance in 50 years).[1]

## File Specifications

**Format:** GeoTIFF raster (compressed in ZIP archive)[1]
**File Size:** 34.6 MB (compressed)[1]
**Resolution:** Approximately 6 km point spacing, interpolated using inverse distance weighting[1]
**Coverage:** Global mosaic (some areas like Greenland are not covered)[2][1]
**Ground Conditions:** Reference rock (Vs30 = 760-800 m/s)[2][1]
**Version:** 2023.1 (released June 2023)[2]

## Authentication & Access

**Registration:** No registration required for the base PGA layer[2]
**Authentication:** None needed - direct download via curl/wget is supported[2]
**Command Line Download:**
```bash
wget https://zenodo.org/records/8409647/files/GEM-GSHM_PGA-475y-rock_v2023.zip
```
or
```bash
curl -O https://zenodo.org/records/8409647/files/GEM-GSHM_PGA-475y-rock_v2023.zip
```

## Cloud Platform Availability

### Google Earth Engine
**Status:** Not available in the public GEE catalog[3][4]
The GEE Data Catalog does not currently include the GEM Global Seismic Hazard Map. Only USGS earthquake datasets are available as private assets in specialized platforms like ClimateEngine.[5]

### AWS Open Data
**Status:** Not found in the AWS Open Data Registry[6][7]
The GEM dataset is not currently available through AWS Open Data. The registry focuses primarily on other geophysical datasets but does not include the GEM hazard maps.[7]

### Microsoft Planetary Computer
**Status:** Not available[8][9]
The Microsoft Planetary Computer catalog does not include seismic hazard datasets from GEM.
