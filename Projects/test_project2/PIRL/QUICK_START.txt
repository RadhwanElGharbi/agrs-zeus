TROUBLESHOOTING
================================================================================

  → Use MLP instead (recommended for vector states)

CUDA out of memory:
  → Reduce num_envs in config or use CPU version

Training very slow:
  → Use GPU version or reduce num_envs

No GeoJSON generated:
  → Increase --max-steps or check model trained successfully
