## 🚀 Creating a New Project

1. Read the project structure standard
2. Create project directory: `/opt/agrs/Projects/<PROJECT_NAME>/`
3. Initialize project structure (Phase 1)
4. **Conduct mandatory Perplexity research** (Phase 2)
5. Fetch and process geospatial data
6. Perform analysis and generate outputs
