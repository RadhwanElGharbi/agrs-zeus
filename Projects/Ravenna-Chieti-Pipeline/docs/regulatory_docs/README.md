## Overview

This directory contains all regulatory documents, technical standards, and legal requirements necessary for compliance with Italian and EU regulations for oil & gas pipeline construction.

The regulatory framework for this project is complex, involving:
- **National level:** Italian Ministry of Environment (MASE), ARERA, SNAM
- **Regional level:** Marche and Umbria Regional Authorities, ARPA agencies
- **Local level:** Municipalities of Serra San Quirico, Fabriano, Terni
- **EU level:** European Commission oversight of gas market interventions
- **International standards:** ASME, ISO, EN, API technical specifications
